# Lampa: «Детям по возрасту»

Плагин для [Lampa](https://github.com/yumata/lampa), который подбирает фильмы, мультфильмы и мультсериалы по возрасту ребёнка (данные TMDB).

## Установка

Настройки → Расширения → Добавить плагин → вставьте ссылку:

```
https://cdn.jsdelivr.net/gh/mvinkarklins/lampa@latest/kids_age.js
```

После перезапуска в левом меню появится пункт **«Детям»**. Номер версии виден в заголовке окна выбора возраста.

## Разработка и выпуск

Есть две ссылки на плагин:

| | Ссылка | Что отдаёт | Обновление |
|---|---|---|---|
| **prod** | `https://cdn.jsdelivr.net/gh/mvinkarklins/lampa@latest/kids_age.js` | последний выпуск (тег `vX.Y.Z`) | после выпуска, до 12 часов |
| **dev** | `https://mvinkarklins.github.io/lampa/kids_age.js` | текущее состояние ветки `main` (GitHub Pages) | через 1–2 минуты после push |

Для проверки изменений поставьте в Лампу dev-ссылку. Когда всё работает, выпустите версию:

1. Поднимите `VERSION` в `kids_age.js` и сделайте коммит.
2. Поставьте тег и отправьте его: `git tag v2.0.1 && git push origin v2.0.1`.
3. Сбросьте кэш jsDelivr: откройте `https://purge.jsdelivr.net/gh/mvinkarklins/lampa@latest/kids_age.js`.

## Как работает

1. Выберите возраст: до 6, 7–9, 10–12, 13–15 лет (последний выбор запоминается).
2. Выберите подборку:
   - мультфильмы: популярные, лучшие, новинки, самые свежие (по дате выхода), кассовые (по сборам в прокате);
   - Студия Гибли: фильмы Хаяо Миядзаки и студии Ghibli, подходящие по возрасту;
   - мультсериалы: популярные, лучшие, хиты (больше всего оценок за последние годы);
   - фильмы: популярные, лучшие, новинки, кассовые;
   - сериалы: популярные, хиты.

Для детей до 6 лет кассовые подборки и хиты берут десять лет, для старших — три года.

Фильтрация:

| Возраст | Фильмы (рейтинг MPAA) | Сериалы (TV Parental Guidelines) | Дополнительно |
|---|---|---|---|
| до 6 | G | TV-Y, TV-Y7, TV-G | мультсериалы жанра «Детский» |
| 7–9 | G, PG | TV-Y, TV-Y7, TV-G | |
| 10–12 | G, PG | + TV-PG | любые мультсериалы |
| 13–15 | G, PG, PG-13 | + TV-PG | + приключенческие и фантастические сериалы |

Фильмы и сериалы без рейтинга США (NR) не показываются.

Всегда исключаются жанры: ужасы, триллер, криминал, военный (для сериалов также новости, реалити, мыльные оперы, ток-шоу).

## Профили с синхронизацией

Плагин `profiles.js` добавляет в левое меню пункт с именем текущего профиля. У каждого профиля свои закладки, история, таймкоды и возраст в «Детям»; настройки TorrServer и парсера общие для всех профилей и устройств.

```
https://mvinkarklins.github.io/lampa/profiles.js
```

Данные хранит свой сервер из папки `sync/` (Node без зависимостей, JSON-файлы на диске NAS). Он работает в microk8s по адресу `http://192.168.1.25`, доступен только в домашней сети и без пароля.

Сборка и запуск:

```
cd sync
docker build -t lampa-sync:1.0.0 .
docker save lampa-sync:1.0.0 | microk8s ctr image import -
microk8s kubectl apply -f k8s.yaml
```

Как работает:

- первое устройство создаёт профиль «Основной» из своих данных;
- новое устройство при запуске предлагает выбрать профиль; при конфликте побеждают данные сервера, остальное добавляется;
- при смене профиля текущие данные отправляются на сервер, затем загружаются данные нового профиля и Лампа перезапускается;
- синхронизация идёт при запуске, через 5 секунд после изменений, каждые 5 минут и при сворачивании приложения; при конфликте побеждает более позднее изменение.

С аккаунтом CUB закладки приходят из облака CUB и могут перебивать профили, поэтому для профилей лучше выйти из CUB.
