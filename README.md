# Lampa: «Детям по возрасту»

Плагин для [Lampa](https://github.com/yumata/lampa), который подбирает фильмы, мультфильмы и мультсериалы по возрасту ребёнка (данные TMDB).

## Установка

Настройки → Расширения → Добавить плагин → вставьте ссылку:

```
https://cdn.jsdelivr.net/gh/mvinkarklins/lampa@latest/kids_age.js
```

После перезапуска в левом меню появится пункт **«Детям»**. Номер версии виден в заголовке окна выбора возраста.

## Разработка и выпуск

Есть две ссылки на плагин:

| | Ссылка | Что отдаёт | Обновление |
|---|---|---|---|
| **prod** | `https://cdn.jsdelivr.net/gh/mvinkarklins/lampa@latest/kids_age.js` | последний выпуск (тег `vX.Y.Z`) | после выпуска, до 12 часов |
| **dev** | `https://mvinkarklins.github.io/lampa/kids_age.js` | текущее состояние ветки `main` (GitHub Pages) | через 1–2 минуты после push |

Для проверки изменений поставьте в Лампу dev-ссылку. Когда всё работает, выпустите версию:

1. Поднимите `VERSION` в `kids_age.js` и сделайте коммит.
2. Поставьте тег и отправьте его: `git tag v2.0.1 && git push origin v2.0.1`.
3. Сбросьте кэш jsDelivr: откройте `https://purge.jsdelivr.net/gh/mvinkarklins/lampa@latest/kids_age.js`.

## Как работает

1. Выберите возраст: до 6, 7–9, 10–12, 13–15 лет (последний выбор запоминается).
2. Выберите подборку:
   - мультфильмы: популярные, лучшие, новинки, самые свежие (по дате выхода), кассовые (по сборам в прокате);
   - Студия Гибли: фильмы Хаяо Миядзаки и студии Ghibli, подходящие по возрасту;
   - мультсериалы: популярные, лучшие, хиты (больше всего оценок за последние годы);
   - фильмы: популярные, лучшие, новинки, кассовые;
   - сериалы: популярные, хиты.

Для детей до 6 лет кассовые подборки и хиты берут десять лет, для старших — три года.

Фильтрация:

| Возраст | Фильмы (рейтинг MPAA) | Сериалы (TV Parental Guidelines) | Дополнительно |
|---|---|---|---|
| до 6 | G | TV-Y, TV-Y7, TV-G | мультсериалы жанра «Детский» |
| 7–9 | G, PG | TV-Y, TV-Y7, TV-G | |
| 10–12 | G, PG | + TV-PG | любые мультсериалы |
| 13–15 | G, PG, PG-13 | + TV-PG | + приключенческие и фантастические сериалы |

Фильмы и сериалы без рейтинга США (NR) не показываются.

Всегда исключаются жанры: ужасы, триллер, криминал, военный (для сериалов также новости, реалити, мыльные оперы, ток-шоу).

## Кнопка «Торренты»

Плагин `torrent_button.js` ставит кнопку «Торренты» прямо на карточку фильма, рядом с «Смотреть» (штатное закрепление долгим нажатием на пультах LG не работает).

```
https://mvinkarklins.github.io/lampa/torrent_button.js
```

По нажатию можно выбрать, где искать: свой парсер из настроек (Prowlarr) публичный JacRed (jac.red, jac-red.ru, jr.maxvol.pro) — запасной вариант, если свой не отвечает, — или «Везде»: свой парсер и jac.red параллельно, результаты вместе без повторов (одинаковое название и размер). По умолчанию кнопка ищет «Везде»; изменить (например, на «Спрашивать каждый раз»): Настройки → Парсер → «Кнопка «Торренты» на карточке». RuTracker и Kinozal закрыты Cloudflare, поэтому в своём Prowlarr они выключены и приходят через jac.red. Публичный парсер подставляется только на один поиск и в настройки не записывается.

## Интерфейс Neo

Плагин `neo.js` — новый вид Лампы с пятью темами: тёмная тема, скруглённые постеры с заметным фокусом, цветной рейтинг; на главной и в подборках над рядами большой блок с фоном, логотипом и описанием фильма под фокусом; в карточке фильма логотип вместо названия и кнопки-«таблетки».

```
https://mvinkarklins.github.io/lampa/neo.js
```

Включается в Настройки → Интерфейс → «Интерфейс Neo», там же «Тема Neo»:

| Тема | Вид |
|---|---|
| Netflix | тёмная, красный акцент, блок с описанием слева |
| Apple TV | мягкие скругления, большой фокус с подсветкой, описание по центру |
| Минимализм | плоская, синий акцент, текстовое название, компактный блок |
| Детская | фиолетово-розовый градиент, крупные скругления, жёлтый фокус, цветные логотипы |
| Кинозал | чёрная с золотом, заглавные буквы в заголовках рядов, строгие кнопки |

Там же «Баннер Neo»: компактный (по умолчанию, около трети экрана: логотип, рейтинг, год, жанры, две строки описания), большой или выключен.

«Постеры Neo»: меньше (по умолчанию, 7–8 постеров в ряд вместо 6), мелкие или обычные.

Фон баннера сначала грузится в 1280 px, а если фокус задержался на фильме дольше секунды — подменяется оригиналом TMDB (обычно 1920×1080, иногда 4K). Размера 1920 у TMDB нет.

Флажок, тема, размер баннера и постеров хранятся в профиле, так что Neo можно включить, например, только в профиле «test». Без флажка плагин ничего не меняет. Логотипы фильмов показываются белым силуэтом (кроме детской темы): у TMDB бывают тёмные логотипы, а цвет картинки из-за CORS не прочитать.

## Дорожки LG

Плагин `lg_tracks.js` добавляет в панель плеера Лампы на телевизорах LG кнопку «Дорожки LG». Штатно Лампа спрашивает у медиасервиса webOS список звуковых дорожек только первую секунду после старта; торрент стартует дольше, список не приходит, и кнопка дорожек не появляется. Новая кнопка запрашивает список по нажатию, когда фильм уже играет (ждёт ответа до 20 секунд), показывает выбор и переключает дорожку, не перезапуская видео. Заодно список передаётся Лампе, и появляется штатная кнопка. На других устройствах плагин ничего не делает.

```
https://mvinkarklins.github.io/lampa/lg_tracks.js
```

## Профили с синхронизацией

Плагин `profiles.js` добавляет в левое меню пункт с именем текущего профиля. У каждого профиля свои закладки, история, таймкоды, возраст в «Детям», выбор парсера для кнопки «Торренты» и включение интерфейса Neo; настройки TorrServer и парсера, а также список установленных плагинов общие для всех профилей и устройств (после смены списка плагинов Лампа перезапускается сама).

```
https://mvinkarklins.github.io/lampa/profiles.js
```

Данные хранит свой сервер из папки `sync/` (Node без зависимостей, JSON-файлы на диске NAS). Он работает в microk8s по адресу `http://192.168.1.25`, доступен только в домашней сети и без пароля.

Сборка и запуск:

```
cd sync
docker build -t lampa-sync:1.0.1 .
docker save lampa-sync:1.0.1 | microk8s ctr image import -
microk8s kubectl apply -f k8s.yaml
```

Как работает:

- первое устройство создаёт профиль «Основной» из своих данных;
- новое устройство при запуске предлагает выбрать профиль; при конфликте побеждают данные сервера, остальное добавляется;
- при смене профиля текущие данные отправляются на сервер, затем загружаются данные нового профиля и Лампа перезапускается;
- в меню профиля есть «Синхронизировать сейчас», а также «Загрузить с сервера» и «Отправить на сервер» — они полностью заменяют данные одной стороны данными другой (с подтверждением);
- синхронизация идёт при запуске, через 5 секунд после изменений, каждые 5 минут и при сворачивании приложения; при конфликте побеждает более позднее изменение.

С аккаунтом CUB закладки приходят из облака CUB и могут перебивать профили, поэтому для профилей лучше выйти из CUB.
