# Lampa: «Детям по возрасту»

Плагин для [Lampa](https://github.com/yumata/lampa), который подбирает фильмы, мультфильмы и мультсериалы по возрасту ребёнка (данные TMDB).

## Установка

Настройки → Расширения → Добавить плагин → вставьте ссылку:

```
https://cdn.jsdelivr.net/gh/mvinkarklins/lampa@main/kids_age.js
```

После перезапуска в левом меню появится пункт **«Детям»**.

## Как работает

1. Выберите возраст: 0–3, 4–6, 7–9, 10–12, 13–15 лет (последний выбор запоминается).
2. Выберите подборку: мультфильмы (популярные / лучшие / новинки), мультсериалы, фильмы, сериалы.

Фильтрация:

| Возраст | Фильмы (рейтинг MPAA) | Дополнительно |
|---|---|---|
| 0–3 | до G | только мультфильмы до 80 минут, мультсериалы жанра «Детский» |
| 4–6 | до G | мультсериалы жанра «Детский» |
| 7–9 | до PG | |
| 10–12 | до PG | любые мультсериалы |
| 13–15 | до PG-13 | + приключенческие и фантастические сериалы |

Всегда исключаются жанры: ужасы, триллер, криминал, военный (для сериалов также новости, реалити, мыльные оперы, ток-шоу).
