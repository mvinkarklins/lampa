# Stremio: «Хиты кино и сериалов»

Дополнение (addon) для Stremio с подборками фильмов и сериалов для взрослых. Данные берутся из TMDB. Детские подборки живут в плагине для Лампы ([kids_age.js](../kids_age.js)).

Каталоги:
- 💰 Кассовые хиты — фильмы, которые собрали больше всего в прокате за последние три года
- ✨ Новинки кино — популярное из вышедшего за полгода, широкими карточками
- 🔥 Хиты сериалов — больше всего оценок среди сериалов, выходивших последние три года
- 🆕 Новые сериалы — премьеры последнего года

В каждом каталоге есть фильтр по жанру (Stremio называет его «Жанр»): боевик, комедия, ужасы и т. д.

На постерах нарисованы возраст («12+», «16+», «18+» по рейтингу США) и оценка TMDB. В описании карточки первой строкой идут возраст, сборы или число оценок, длительность (или число сезонов) и жанры.

Дополнение отдаёт только каталоги, а карточки выдаёт с IMDb ID. Поэтому описание и видео подтянут дополнения, которые у вас уже установлены (Cinemeta и другие).

## Что нужно

1. **Ключ TMDB.** Он бесплатный: зарегистрируйтесь на themoviedb.org, затем Settings → API → API Key.
2. **Место, где запустить сервер.** Stremio обращается к дополнению по ссылке, поэтому сервер должен работать постоянно.

## Запуск на своём компьютере

Нужен Node.js 18.17 или новее.

```
cd stremio
npm install
TMDB_API_KEY=ваш_ключ npm start
```

Затем в Stremio: Дополнения → поле поиска → вставьте `http://127.0.0.1:7000/manifest.json` → Установить. Так дополнение работает только в Stremio на этом же компьютере.

## Запуск в Docker

```
cd stremio
TMDB_API_KEY=ваш_ключ docker compose up -d --build
```

Или без compose:

```
cd stremio
docker build -t stremio-hits .
docker run -d -p 7000:7000 -e TMDB_API_KEY=ваш_ключ stremio-hits
```

В `k8s.yaml` лежит пример для Kubernetes (microk8s с MetalLB): под с аддоном и nginx, который отдаёт HTTPS. Stremio устанавливает дополнения по `http://` только с `127.0.0.1`, поэтому для других устройств нужен HTTPS с сертификатом, которому доверяет само устройство. Свой CA на телевизор не поставить, поэтому nginx отдаёт аддон ещё и по имени [local-ip.sh](https://local-ip.sh): `https://192-168-1-2.local-ip.sh/manifest.json` указывает на адрес в домашней сети и имеет сертификат Let's Encrypt, который nginx сам скачивает и обновляет.

## Запуск в интернете (для ТВ, телефона, приставки)

Подойдёт любой хостинг для Node.js, например Render.com (бесплатный тариф):

1. New → Web Service, выберите этот репозиторий.
2. Root Directory: `stremio`.
3. Build Command: `npm install`, Start Command: `npm start`.
4. Environment: `TMDB_API_KEY` = ваш ключ.

После деплоя установите в Stremio ссылку вида `https://<ваш-сервис>.onrender.com/manifest.json`.

На бесплатном тарифе Render сервис «засыпает», если к нему долго не обращаться, и первый запрос после этого идёт медленно.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TMDB_API_KEY` | — | ключ TMDB (обязательно) |
| `PORT` | `7000` | порт сервера |
| `LANGUAGE` | `ru-RU` | язык названий и описаний |
| `PUBLIC_URL` | из запроса | внешний адрес сервера для ссылок на постеры и иконку, например `https://hits.example.com` |
| `CACHE_DIR` | — | папка для кэша постеров с метками (в Docker — `/tmp/posters`) |
