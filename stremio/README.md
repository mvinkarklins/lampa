# Stremio: «Детям по возрасту»

Дополнение (addon) для Stremio с каталогами для детей. Данные берутся из TMDB, фильтры те же, что в плагине для Лампы.

Каталоги:
- 🎨 Мультфильмы для детей
- ✨ Новые мультфильмы — популярные за последний год, широкими карточками
- 🆕 Свежие мультфильмы — самые последние вышедшие, по дате выхода
- 📺 Мультсериалы
- 🎬 Детское кино
- 🍿 Сериалы для детей

Возраст выбирается в фильтре каталога (Stremio называет его «Жанр»): 0–3, 4–6, 7–9, 10–12, 13–15 лет. Если возраст не выбран, используется 4–6 лет. Другое значение по умолчанию задаётся переменной `DEFAULT_AGE`, например `7-9`.

На постерах нарисованы возраст («0+», «6+», «12+») и оценка TMDB. В описании карточки первой строкой идут возраст, длительность (или число сезонов) и жанры.

Фильмы отбираются по рейтингу MPAA, сериалы — по рейтингу TV Parental Guidelines:

| Возраст | Фильмы | Сериалы |
|---|---|---|
| 0–3 | G, до 80 минут | TV-Y, TV-G |
| 4–6 | G | TV-Y, TV-Y7, TV-G |
| 7–9 | до PG | TV-Y, TV-Y7, TV-G |
| 10–12 | до PG | + TV-PG |
| 13–15 | до PG-13 | + TV-PG |

Дополнение отдаёт только каталоги, а карточки выдаёт с IMDb ID. Поэтому описание и видео подтянут дополнения, которые у вас уже установлены (Cinemeta и другие).

## Что нужно

1. **Ключ TMDB.** Он бесплатный: зарегистрируйтесь на themoviedb.org, затем Settings → API → API Key.
2. **Место, где запустить сервер.** Stremio обращается к дополнению по ссылке, поэтому сервер должен работать постоянно.

## Запуск на своём компьютере

Нужен Node.js 18.17 или новее.

```
cd stremio
npm install
TMDB_API_KEY=ваш_ключ npm start
```

Затем в Stremio: Дополнения → поле поиска → вставьте `http://127.0.0.1:7000/manifest.json` → Установить. Так дополнение работает только в Stremio на этом же компьютере.

## Запуск в Docker

```
cd stremio
TMDB_API_KEY=ваш_ключ docker compose up -d --build
```

Или без compose:

```
cd stremio
docker build -t stremio-kids .
docker run -d -p 7000:7000 -e TMDB_API_KEY=ваш_ключ stremio-kids
```

В `k8s.yaml` лежит пример для Kubernetes (microk8s с MetalLB): под с аддоном и nginx, который отдаёт HTTPS. Stremio устанавливает дополнения по `http://` только с `127.0.0.1`, поэтому для других устройств нужен HTTPS.

## Запуск в интернете (для ТВ, телефона, приставки)

Подойдёт любой хостинг для Node.js, например Render.com (бесплатный тариф):

1. New → Web Service, выберите этот репозиторий.
2. Root Directory: `stremio`.
3. Build Command: `npm install`, Start Command: `npm start`.
4. Environment: `TMDB_API_KEY` = ваш ключ.

После деплоя установите в Stremio ссылку вида `https://<ваш-сервис>.onrender.com/manifest.json`.

На бесплатном тарифе Render сервис «засыпает», если к нему долго не обращаться, и первый запрос после этого идёт медленно.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TMDB_API_KEY` | — | ключ TMDB (обязательно) |
| `PORT` | `7000` | порт сервера |
| `LANGUAGE` | `ru-RU` | язык названий и описаний |
| `DEFAULT_AGE` | `4-6` | возраст, если в фильтре ничего не выбрано |
| `PUBLIC_URL` | из запроса | внешний адрес сервера для ссылок на постеры и иконку, например `https://kids.example.com` |
| `CACHE_DIR` | — | папка для кэша постеров с метками (в Docker — `/tmp/posters`) |
